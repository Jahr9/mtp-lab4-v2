## Ход выполнения

### Фильтрация

`filter` принимает функцию-предикат `lambda n: n % 2 == 0` (с проверкой типа)
и оставляет только чётные числа. Итератор превращается в новый список.
Порядок и повторы сохраняются, исходный список не меняется.
Ноль и отрицательные чётные числа также включаются. Пустой ввод даёт [].
Допускаются и генераторы; bool, дроби и строки отклоняются.
Время O(n), память результата O(k), где k — число чётных элементов.

### Факториал

`reduce(mul, range(1, n + 1), 1)` последовательно умножает аккумулятор
на числа от 1 до n. Начальное значение 1 обеспечивает правильное 0! = 1.
Примеры: 1! = 1, 5! = 120. Отрицательное n вызывает `ValueError`,
нецелое значение — `TypeError`. Выполняется n умножений; стоимость больших
целых возрастает с длиной результата. `math.factorial` используется только
в тестах как независимый эталон для n от 0 до 100.

### Логирование

`log_calls` принимает функцию и возвращает обёртку. Перед вызовом записывает
имя и аргументы, после — результат; при исключении записывает ошибку
и повторно поднимает то же исключение. Аргументы передаются через
`*args, **kwargs`. `functools.wraps` сохраняет имя, docstring и `__wrapped__`.
Настройка logging находится в точке входа, импорт модуля её не меняет.

### Мемоизация

`memoize` хранит словарь в замыкании. Сначала `inspect.signature.bind`
сопоставляет параметры с аргументами, затем `apply_defaults` добавляет
значения по умолчанию. Поэтому `f(3)`, `f(a=3)` и `f(3, b=2)` при сигнатуре
`f(a, b=2)` используют одну запись. Именованные аргументы `**kwargs`
сортируются, `*args` сохраняются кортежем.

При промахе функция вычисляется один раз, результат сохраняется, включая
`None`. Исключения не сохраняются. Методы `cache_clear()` и `cache_size()`
позволяют сбросить и проверить кэш. Тест рекурсивного Фибоначчи подтверждает:
fib(10)=55, выполнено 11 вычислений для аргументов 0…10.

Ограничения: декоратор предназначен для чистых синхронных функций
с хешируемыми аргументами и результатами, которые клиент не изменяет.
Кэш не ограничен по размеру и не синхронизирован между потоками.
Ключи используют обычное равенство Python: например, 1 и 1.0 равны;
для функций, различающих эти типы, этот декоратор не подходит.

### Декоратор с параметрами

`repeat(times)` имеет три уровня: фабрика получает число повторов,
декоратор получает функцию, обёртка получает аргументы вызова.
`@repeat(times=3)` вызывает функцию ровно три раза и возвращает список
трёх результатов. При times=1 получается список из одного результата.
Ноль, отрицательные и нецелые значения отклоняются. При исключении повторы
прекращаются. Это учебный пример: побочные эффекты функции тоже повторяются.
